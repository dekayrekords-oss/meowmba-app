# Companion behavior update — 1.3.97 / 153

Owner requests: preserve the selected baseline avatar with brief sporadic idle visits,
show Needle 3 runtime status, prevent self-speech replies, and react to music playback.

## Behavior

- Idle characters are non-persisted overlays. A random 60–240 second quiet gap precedes
  a 3–6 second visit; the selected authored/generated baseline is excluded from the
  pool and restored afterward. Activity interrupts visits and restarts quiet time.
  Fixed-interval/randomness sliders are replaced by a clear optional idle-visits toggle.
  Legacy preferences are retained for compatibility but do not drive this schedule.
- Generated baselines no longer mask a temporary authored character. Selecting a new
  baseline, disabling visits, stopping the director, conversation, music, driving,
  hidden/paused stage or active work clears/prevents the overlay.
- Needle 3 appears on the home screen and Models page with separate not-downloaded,
  downloading, ready/on-demand, loading, running, loaded/idle and failure states.
  Native callbacks distinguish inference from readiness; the model is not kept busy
  merely to display “running.” Models offers download/retry. Deletion clears readiness.
- Echo matching retains all streamed sentences and an eight-second completion tail.
  Own spoken wake phrases cannot bypass filtering. During playback interruption
  requires an explicit wake/stop phrase (or the microphone button). Short user
  confirmations are not discarded solely because their words occurred in a longer reply.
- Foreground music awareness reads Android playback state and optional MediaSession
  title/artist, excluding Meow's own session. AudioManager provides a metadata-free
  fallback, with own TTS suppressed. Playback metadata clears on pause. No music
  recording or beat/BPM inference is performed.
- “Dance to music” uses the existing Pocket Groove animation and stage/thermal/privacy
  rules. Dance ownership is tracked so pausing music does not cancel a separately
  requested performance. Spoken “what's playing” queries use the available metadata.
- Avatar settings provides “Music access” to Android notification-access settings.
  The connected phone did not grant Meow this access at inspection. No permission
  was automatically granted; exact titles depend on permission and the media player.
