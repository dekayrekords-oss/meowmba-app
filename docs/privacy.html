Privacy

Last updated 19 August 2026. This is the policy for the Android app Meowmba (com.meow.meowmba).

Meowmba is a voice companion that runs on your phone. The developer does not run an account system or an analytics backend. Chat, memories, and API keys stay on the device unless you turn something on in Settings.

What the app uses

  • Microphone — talk to Meow, the wake phrase, optional background listen, and live notes. Dictation may use the phone’s speech service (often Google) or an on-device recognizer.
  • Camera — face and hand tracking, and photos you ask it to take. Tracking runs on the device.
  • Location — only when you ask for directions or nearby places.
  • Bluetooth — optional LOOI robot body.
  • Calendar — only when you ask to read or add events.
  • Photos / media — only if you ask to tidy the phone. Deletes use the system confirm sheet.
  • Usage access — only if you ask which unused apps are taking space.
  • Notification access — optional road alerts (Waze / Maps). Off until you enable it in system Settings.
  • Accessibility — optional, off until you enable it in system Settings. Used to tap, type, or scroll when you ask. Risky actions still need your OK.
  • Notifications — wake, download, and reply alerts.
  • Screen capture — optional screen watch, off until you turn it on.

What stays on the phone

  • Chat history, memories, live notes, voice prints, and settings. Voice prints never leave the phone. They are only used to recognize a name you enrolled.
  • API keys, encrypted on the device.
  • On-device models you download (including the first-launch voice models).

Cloud backup of that data is off.

What can leave the phone

Only if you turn it on:

  • A cloud brain you configure (OpenRouter, OpenAI, BigPickle, or a server you type). That provider sees the text you send, under their policy.
  • A Hugging Face token — for model downloads you start.
  • A LAN server you typed (Ollama, Hermes, image / music / video). HTTP is allowed only on your own network. Public sites must be HTTPS.
  • Maps or search when you ask for directions or a web lookup.
  • Speech recognition — the system recognizer may send audio to the device vendor while you dictate.

We do not sell data. We do not run ads. We do not have our own analytics backend.

Deletion

Delete chat in the app, or uninstall / clear app storage. There is no server copy to request.

Children

Meowmba is not directed at children under 13.

Contact

Use the email on the Play Store listing for this app.
