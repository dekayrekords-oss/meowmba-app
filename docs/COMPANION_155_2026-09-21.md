### Song identification

Known phone-player title/artist queries retain the local metadata path. Nearby-song
requests open an explicit dialog. After an AudD key is configured in Avatar settings,
“Listen and identify” requests Android microphone permission if necessary, captures
10 seconds of mono PCM audio, and submits WAV audio directly to AudD over HTTPS.
The encrypted key is entered privately on the device, never bundled in the app.
[AudD's official API contract](https://docs.audd.io/) requires an API token.

The sample is held in memory, not saved to a phone file. A temporarily enabled microphone
returns to its previous off state after capture or cancellation, without changing the saved
preference or arming always-on listening. Recording and HTTP requests
are cancellable and time-bounded. Leaving the foreground, disabling the microphone,
starting another chat action, or cancelling revokes the lookup. Voice/wake capture
yields while the identification dialog owns the mic. No-match, permission, network,
provider and capture errors have distinct honest feedback. The API does not guarantee
recognition of humming, live covers or an arbitrary song; no such claim is made.

An AudD account/key is still required for end-to-end acceptance. No key was invented,
no paid account was provisioned, and no live sample was uploaded during this work.
The optional existing notification access is separate: it supplies a phone player's
shared track details and is not required for microphone identification.

### Chat and layout

The chat microphone tap now explicitly enables the app's microphone switch, obtains
Android permission if needed, and starts a turn. It cancels an existing reply before enabling a disabled mic, including before a permission
request. It does not first arm the automatic listener and then accidentally submit that new turn. The phone button starts/ends
voice conversation with Meow. Listening, permission/error captions and active-call
feedback are visible inside the chat panel. AudD setup replaces the chat panel with
Avatar settings, preserving sensor choices.

The home privacy buttons occupy one bottom control row below the caption area, and
hide behind expanded chat. Duplicate canvas badges and the bottom text copy are
removed from the home renderer; the actual labeled privacy controls remain. Needle 3
runtime/download status remains in Models, with no home status line.
