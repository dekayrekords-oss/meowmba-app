## Lessons for future Meow work

The historical Play listing explicitly says not to publish it unchanged. Avoid its broad local-only data claim: speech, cloud models, MCP, and connected services can have distinct data flows. Recent build handoffs also supersede old gesture descriptions; build 109 says the video button owns the camera, whereas older README text described tapping eyes. Read the installed-version handoff and film the real controls.

A connector catalog card is not evidence of a live adapter. A source tool declaration is not evidence that it is registered or usable. A chat message claiming an action happened is not proof: inspect the real artifact, device state, and audit result. Media generation can return fallback output; identify its backend in the video. Synthetic neural behavior is separate from biological research, and physical robot behavior is unverified without hardware.
