# First recording scripts

Drafts for real screen recordings; no footage or finished videos exist yet. Narration is conditional on a successful demonstration in the installed build. Replace any unsupported step before recording. Timing is an editing target.

## 00 — Small Ideas, Real Apps: What We’re Building (60 seconds)

**Thumbnail:** LET’S BUILD APPS

| Time | Picture | Narration |
|---|---|---|
| 0–8s | A simple app sketch followed by a real working app | “We take everyday problems and turn them into apps. This channel shows how.” |
| 8–18s | A spoken question and actual answer | “Some projects start small: one idea, one useful feature, and a first version.” |
| 18–28s | Meow demo, then a second verified project or a clearly labeled concept sketch | “Others grow into bigger projects, like Meow Assistant—and soon, bringing up AIOS.” |
| 28–40s | A test project and a sanitized, verified server-status view | “We’ll mix app ideas, working builds, and a look at how we run Meow, our server.” |
| 40–50s | Show a readable code diff and a verified test result | “And when something breaks, we’ll walk through the clues, the fix, and how we checked it.” |
| 50–60s | End on a sketch becoming a working interface; avoid implying an unbuilt concept is finished | “Bring an idea and build along with us. We’ll share what works and what we learn.” |

Description: “Simple ideas, real apps, and the server behind our work. Follow our current and future projects through builds, demos, coding with AI, managing Meow server, the upcoming AIOS bring-up, and real troubleshooting.” Add the recorded version and verified links before uploading.

## 01 — Your First Conversation with Meow (2–3 minutes)

**Thumbnail:** SAY HELLO

Opening: “Let’s get from opening Meow to hearing its first answer.”

1. Show the installed version and provider prerequisites. Narrate: “This demonstration uses [actual provider and model].”
2. Open the setup flow or the corresponding current settings. Record the real labels. Narrate: “Choose the model connection you want to use. Follow the setup steps shown on your phone.”
3. Enable microphone access through the actual flow. Narrate: “Microphone access lets Meow hear this conversation.”
4. Tap the microphone and say: “Hello Meow. Give me one idea for a rainy afternoon.” Keep the actual answer.
5. Open text chat and type a follow-up. Narrate: “You can also type here.”
6. Show the current stop/mute control. Narrate: “Use this control when you want the voice to stop.”

Closing: “You’ve had your first conversation. Next, we’ll change how Meow looks.”

If a response fails: show the actual provider error and fix the connection before recording the successful run. Do not describe generated captions as proof that speech audio worked.

## 02 — Make Meow Look Like Yours (2–3 minutes)

**Thumbnail:** MAKE IT YOURS

Opening: “Here’s how to change Meow’s look and make it fit your screen.”

1. Show the starting avatar.
2. Open avatar setup. Show Look and select an option that exists in the installed version.
3. Show Space and adjust size or placement. Narrate the actual effect.
4. Open Behavior and point out the current expression and playfulness settings.
5. Open Animations and play one available animation.
6. Return to the companion and show the result at normal speed.

Closing: “That’s my setup. Try a different look, then choose an animation you like.”

Use the current build: the build 109 handoff describes Look, Space, Behavior, and Animations. Verify labels again before filming. Do not demonstrate old eye-tap camera instructions from the historical README.

## 03 — Teach Meow to Remember (2–3 minutes)

**Thumbnail:** MEOW REMEMBERS

Opening: “Let’s give Meow a harmless fact and see whether it can find it later.”

1. Say or type: “Remember that my demo project is called Moon Garden.”
2. Open Memory and show the saved entry. Narrate: “Here’s the fact that was saved.”
3. Start a later interaction and ask: “What is my demo project called?”
4. Keep the actual answer and verify that the saved memory was recalled. A same-chat repetition alone is not proof of long-term recall.
5. Show the available memory management controls and remove the test fact if supported.

Closing: “Use memory for details you want to keep, and review what’s saved.”

Do not claim cross-device synchronization or fully local processing without verifying the selected provider and memory path.

## 04 — Turn Speech into a Note (2–3 minutes)

**Thumbnail:** TALK TO NOTES

Opening: “I’m going to turn a short spoken idea into a saved note.”

1. Open the current notes/Vault flow or verify the “start taking notes” command first.
2. Dictate: “Moon Garden video ideas: introduce Meow, change the avatar, and demonstrate memory.”
3. Stop the note session with the actual supported control.
4. Open the saved note and compare it with the spoken content.
5. Reopen the note to demonstrate persistence.

Closing: “Your idea is now a note you can come back to.”

Record any transcription correction honestly. Do not call a generated summary a verbatim transcript.

## Reusable script for every remaining feature

- Result first: “Here’s how to [one outcome] with Meow.”
- Requirements: identify actual version, provider, permissions, service, or hardware.
- Demonstration: show the exact request or controls, wait for completion, open the real result.
- Practical limit: explain one observed limitation and the relevant stop/undo control.
- Closing: “Next, try [related feature].” Link only after that video is published.

For lab episodes, say “experimental” in the opening and title. Show measured behavior and explain what remains unverified.
