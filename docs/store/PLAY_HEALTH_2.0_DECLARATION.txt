Meow Assistant uses android.permission.ACTIVITY_RECOGNITION after the user grants Android permission to receive activity-transition labels such as walking, running, cycling, still and in-vehicle. These labels provide optional context for Flow's on-device journal and the companion's conversations; the in-vehicle state also adjusts update cadence when optional foreground Flow location is enabled. This supports the companion and project workspace by keeping available activity context with the user's saved work.

Activity context is stored on the phone. Relevant context may be included in a conversation with a cloud AI provider selected by the user, as explained in the app disclosure and privacy policy. Users can decline or revoke activity-recognition permission. Meow does not use Health Connect permissions or present activity labels as clinical measurements.

The optional compatible Bluetooth ring offers local, on-demand battery, step and experimental wellness sensor tests. Ring readings use the ring's Bluetooth connection rather than ACTIVITY_RECOGNITION, stay in memory on the phone and are excluded from shared diagnostic logs. The app is not intended for diagnosis or treatment.
