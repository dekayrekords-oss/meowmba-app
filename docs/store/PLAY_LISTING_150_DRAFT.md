## Short description

An animated AI companion for chat, voice, notes and everyday tasks.

## Full description

Meow Assistant combines an animated companion with text and voice conversations.
Choose a supported AI provider or a compatible on-device model, then use the features
you want. Cloud services may require your own account, API key or subscription.

- Chat by text or voice and customize your companion's appearance.
- Keep local notes, memories and generated files.
- Open apps, prepare drafts, use supported tools and review requested actions.
- Connect a supported Computer workspace for approved tasks and view verified small-file results.
- Control microphone and camera modes explicitly.
- Share an optional diagnostic report when you need support.

Some features need model downloads, device permissions, a configured service or separate
hardware. Availability, speed and quality depend on your phone, model and provider.
Large Computer file transfers and a unified project workspace remain under development.
Autonomous control of other apps' screens is not included in this Play edition.
Robot motion is not available; optional wearable and hardware features require separate validation.

Local history is stored on the phone. Requests sent to a configured cloud model or
connected service can include the text, audio, images, files or relevant context needed
for that feature. Review the privacy policy and the selected provider's terms.
Microphone/camera modes can be turned off, and diagnostic reports are shared only when you choose.
