# UI and optimization review — September 5, 2026

Later release override: the user paused 3D work. The model renderer, library
picker and Filament dependencies have been removed from app source sets.
3D findings below describe the earlier prototype only, not the release app.

User-requested independent agent review completed read-only. Integrator applied
the following fixes while preserving existing work in the checkout:

- Compact, content-sized reply/composer replaces the fixed 60% chat panel.
  Full conversation history is an explicit control; close retracts the panel.
- Streaming assistant text is displayed in chat itself, rather than behind it.
  Provider errors and watchdog timeouts also reach the visible reply area.
- Separate saveable drafts per conversation survive collapse and recreation.
  Live mic transcripts cannot overwrite a typed draft.
- Long replies can be scrolled and selected; persistence does not reset the
  reader's position. Completed transient replies retire when the saved row arrives.
- Assistant reply persistence retains the originating conversation when the
  user switches projects during generation.
- Collapsing chat preserves voice calls. A collapsed call has Open/Hang-up controls.
- 3D microphone indicators use microphone state, separately from voice-output
  mute. Model capability details moved into the Avatar library, outside the stage.
- Avatar rendering pauses behind opaque screens including settings, connectors
  and onboarding. Compact chat leaves the visible avatar alive.

Validation: Compose/Robolectric interaction tests cover collapse/reopen, streaming
visibility, independent transcripts and per-project saved-state restoration.
Targeted model/appearance tests and an APK build accompany this checkpoint.
The broader VoicePipelineTest run was stopped after stalling; it is not counted
as a passing regression run. Initial UI test-host manifest configuration was
fixed by including Android resources in unit tests.

Still requires phone verification: folded/unfolded and landscape keyboard layout,
large fonts/TalkBack, real call continuity, the imported GLB in Filament and
actual frame-time/CPU/GPU measurements. Reduced hidden rendering is a code-level
optimization; no measured battery or frame-rate improvement is claimed.

Model artifact: `art/avatars/snow-cat/snow-cat.blend` and `snow-cat.glb`, with a
rendered preview. It is an original first model inspired by the supplied image,
not a finished fur groom or automatically installed avatar.
