This integrates Claude's `feature/meow-flow-core@28a9a72` and preserves a snapshot of
Claude's uncommitted `perf/idle-heat-20260922` work (14 files, based on `637697f`).
The original performance checkout is untouched. No public source upload.
Installed source is local commit `1ef898c9fa31298fb4ba7f7c8c8d18e0e99be850`.

## Changes

- Flow is an app layout beside Companion and Professional; Desk is a selectable avatar.
  Both use the same persistent task store. Add task, Done, Later, chat, microphone,
  theme adjustment and optional calendar access are connected.
- Room 10 → 11 adds Flow tables without replacing existing data. Closed tasks no longer
  populate the live in-memory list. Notification actions persist even after process death.
- Removed the false claim that Laya is running. This build uses local rules; neither Laya
  nor Jev is connected. Optional model work remains gated on a real device benchmark.
- Fixed unknown calendar availability being displayed as free time, ongoing events being
  shown as free time, and unrelated meetings promoting every undated People task.
- Evidence is applied before scheduling decisions, including evidence arriving before start.
- Setup uses OS RAM, storage, core count, low-RAM status and CPU ABI. Light defaults select
  Classic, a still background and 15 FPS; Balanced selects 24 FPS; Full selects 30 FPS.
  Only absent preferences are initialized. Existing appearance choices remain overrides.
- Phone Computer is recommended only with a supported 64-bit CPU, at least 7 GiB reported
  RAM, six cores, and 8 GB free storage. Other phones see a lighter recommended setup path
  and can deliberately proceed with Computer. No automatic Termux start, model download,
  sensor permission or provider switch. These are conservative heuristics, not a GPU benchmark.
- Shared animation timing reduces duplicate window redraws; frame loops sleep through
  rejected frames; drawing colors and Reflex text reuse exact previously computed results.
- Music metadata uses session callbacks while foregrounded; the existing light dance tick
  reads cached metadata. Background cleanup unregisters listeners.
- Desk walking uses bounded cadence, pauses with lifecycle/thermal state and disables wandering
  at the lowest FPS setting. Flow's periodic refresh runs only while the Activity is started.
- Flow and Desk stop hidden companion animations. Desk no longer renders a hidden animated
  background; old Reflex/clock/weather overlays no longer cover the new screens' controls.
- A non-debuggable, shrunk `daily` variant keeps preview package `com.example.meowmba` and its
  existing signing certificate. Play package/signing remains separate.

## Performance measurements

Baseline: preview 152, folded cover display, Lumen panda and cloudy background, USB powered,
mic/camera off. A 63.4-second idle sample measured 53.08% of one CPU core and 30.52 drawn
frames/second; thermal status stayed 0. This is not a battery drain measurement.

Final Flow: 604.8 seconds, 0.96% of one CPU core, 0.02 drawn frames/second, foreground for
every sample. All 21 thermal samples were status 0; battery 34.8 → 34.4°C, skin 37.9°C.
This demonstrates low idle work on this phone; it is a different scene from Lumen.

Final Desk: 604.6 seconds, 1.78% of one CPU core, 1.36 drawn frames/second with idle
blinking/tail/wandering enabled, foreground for every sample. All 21 thermal samples were
status 0; battery 34.3 → 34.7°C, skin 37.9°C. Neither mode exceeded normal thermal status
in the sampled checks; the phone remained USB-powered throughout.

Final Lumen: 63.0 seconds, 47.49% of one CPU core, 24.67 drawn frames/second, foreground
throughout; thermal status 0, battery 34.6°C unchanged. Saved animal preferences were not
changed, but the observed forms differed (baseline capture panda, final capture cat), so
the difference from 53.08% is not a controlled like-for-like improvement claim. Detailed
Lumen remains much heavier than Flow/Desk; older-phone defaults therefore select Classic.
The earlier RC1 Lumen sample changed screens before completion and is excluded entirely.

Final crash-buffer check after all runs: zero Meow entries. The phone is left in Companion /
Lumen with the saved animal selection, microphone off and camera off. Source is committed
locally; the report and build authority record the exact package, source and test evidence.

## Using the new views

- Settings → Appearance → Flow opens Meow Flow. Add task saves a task on this phone;
  Done records completion; Later hides it for an hour. Ask opens the existing chat.
- Desk in Flow opens Meow's Desk. Tapping a desk object returns to the saved tasks in Flow.
  Settings → Appearance → Companion restores the companion layout; choose the Lumen
  avatar again if you selected Desk. The animal selection remains separate.
- Adjust changes Flow's presentation. Calendar and notification access are optional and
  requested only when the user chooses to connect them.
- Fresh setup shows "Tuned for your phone". Less capable phones skip the Computer page
  automatically, while Computer remains available in Settings for a deliberate manual setup.

## Limits

Laya inference, Jev API use, geofencing, automatic semantic intention capture, background
usage/notification evidence, external action execution from Flow, and Play submission are
not completed by this change. Flow's Done button records completion; it does not claim to
execute the task. No broad battery-life claim follows from a short USB-connected test.
Older-device and unplugged battery acceptance remain unmeasured. Hardware defaults are
conservative OS-metadata heuristics, not a model inference or GPU speed test. Meow server
SSH was unreachable during this work; source has not been pushed to that server.
This build retains the existing Android 12 minimum.
