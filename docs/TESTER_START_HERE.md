# Help test Meow Assistant

Meow Assistant is an early Android beta. We want honest feedback from real people—not ratings or artificial installs. Android 12 or newer is required, and this build supports ARM64 phones. Local AI/voice downloads can be large; cloud features may need your own API key and may incur provider charges.

## Join in three steps

1. Email **dekayrekords@gmail.com** with the Google Play email you want added to the test. Do not send passwords or API keys.
2. Wait for access confirmation, then use that same Google account to [join the closed test](https://play.google.com/apps/testing/com.meow.meowmba).
3. Install through the Play page and remain opted in for at least **14 continuous days**. Please try the app on several days and send feedback about what works and what does not.

If you see “not available,” check that you were added to the tester list and that Play Store and the signup page use the same Google account. Joining the email list alone does not opt you in.

## Your first five minutes

- Finish or skip guided setup. Do not enter a cloud key unless you want that service.
- Tap the background to open the tiles. Open Chat and type “Open Chrome.”
- Try an avatar reaction, such as “Play a happy bop.”
- Try voice after its model download completes. Check download progress and retry errors in Hardware or Voice recognition.
- In the upcoming Files update, import a non-sensitive test photo, search by its name, and reopen it. Cleanup should offer a review before moving selected files to Trash. Use disposable test assets when testing deletion.

The current Play release is **1.3.22** (verified September 6, 2026). Files, four local neural voices, and the new beta-help panel are in newer development builds and are not yet in that Play release. Do not report those features missing as a new regression until the update is available.

## Give useful feedback

Send feedback to **dekayrekords@gmail.com**. The upcoming update also has Settings → Beta help & feedback → Write feedback.

- Phone model and Android version
- Meow app version
- What you tried, in order
- What you expected versus what happened
- Whether it happens every time
- Optional screenshot with private information removed

Never include passwords, API keys, private chats, or sensitive files. No positive review or public rating is required.
